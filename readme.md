# MakeyMakey 반응속도 게임

MakeyMakey 보드와 알루미늄 호일로 만든 트리거로 조작하는 파이썬 반응속도 게임입니다.
"전도성 재료로 회로 완성 → 키보드 입력 발생"이라는 MakeyMakey의 기본 원리를 직접 배선하고,
그 입력을 파이썬 코드(pygame)로 받아 게임을 만드는 것까지 이어가는 스터디 기록입니다.

## 동작 원리

MakeyMakey는 새로운 신호를 만드는 장치가 아니라 **키보드를 흉내 내는 장치**입니다.
보드의 특정 핀이 **EARTH(접지)** 핀과 전기적으로 연결되는 순간, 컴퓨터에는 정해진 키(예: 방향키, 스페이스)가
눌린 것으로 전달됩니다. 사람의 몸이나 알루미늄 호일처럼 전도성이 있는 물체는 모두 이 회로의 일부가 될 수 있습니다.

```
EARTH(접지) --- (사람 몸 / 손) --- 호일 버튼 --- LEFT 또는 RIGHT 핀
```

위 회로가 완성되는 순간 컴퓨터는 실제 키보드의 왼쪽/오른쪽 화살표 키가 눌린 것처럼 인식합니다.
따라서 파이썬에서도 일반 키보드 게임과 동일한 방식(`pygame`의 `KEYDOWN` 이벤트)으로 입력을 받을 수 있습니다.

## 하드웨어 구성

| 항목 | 연결 |
|---|---|
| EARTH 핀 | 악어클립 → 손 또는 접지용 패드 |
| LEFT(←) 핀 | 악어클립 → 왼쪽 호일 버튼 |
| RIGHT(→) 핀 | 악어클립 → 오른쪽 호일 버튼 |

- 악어클립 3개, 알루미늄 호일 버튼 2개로 구성
- USB 케이블: MakeyMakey는 **미니 USB(Mini-B)** 단자를 사용 (마이크로 USB와 혼동 주의)
- 드라이버 설치 없이 연결 즉시 키보드 장치로 인식됨

## 게임 설명 (`reaction_pygame.py`)

화면에 무작위로 **"LEFT!"** 또는 **"RIGHT!"**가 표시되면, 해당 방향의 호일 버튼을 최대한 빨리 터치하는
반응속도 게임입니다.

- 총 5라운드 진행
- 자극이 뜨기 전 무작위 대기 시간(1~3초)을 두어 예측 터치를 방지
- 자극 표시 시각과 입력 시각의 차이를 `time.time()`으로 측정해 반응시간(ms) 기록
- 너무 빨리 누르거나(자극 뜨기 전), 반대 방향을 누르면 해당 라운드는 실패 처리
- 5라운드 종료 후 평균 반응시간과 최고 기록 출력

## 실행 방법

### 1. 요구 사항
- Python 3.8 이상
- `pygame` 라이브러리

### 2. 설치

```bash
python3 -m pip install pygame
```

### 3. 실행

```bash
python3 reaction_pygame.py

## 또는
python reaction_pygame.py
```

- 보드를 위 하드웨어 구성대로 배선한 상태에서 실행하세요.
- 시작 화면에서 아무 키나 누르면 게임이 시작됩니다.


## 학습 포인트 정리

1. MakeyMakey는 GND(접지)와 특정 핀이 연결되면 정해진 키 입력을 발생시키는 키보드 에뮬레이터다.
2. 사람 몸, 과일, 알루미늄 호일 등 전도성 물체는 모두 회로의 스위치 역할을 할 수 있다.
3. MakeyMakey의 입력은 운영체제 입장에서 일반 키보드 입력과 동일하므로, 별도의 전용 API 없이
   `pygame`의 표준 키보드 이벤트로 하드웨어 입력을 받을 수 있다.
